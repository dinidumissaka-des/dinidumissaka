# Global Design System: Dinidu Missaka Portfolio

## 1. Visual Philosophy
- **Modern Minimalist / Tech-Optimist:** The design uses ample whitespace, sharp edges, and high-contrast typography to convey a "clean" and "professional" senior-level designer brand.
- **AI-Integration Focus:** Subtle nods to automation and "system thinking" through structured grids and technical tool icons (Figma, Framer, Claude).
- **Interactive Depth:** Heavy use of scroll-triggered animations (fade-ins, scaling) and hover states to make the static content feel dynamic.

## 2. Typography
- **Headings:** Bold, high-weight Sans-Serif (likely *Inter* or *General Sans*).
  - *Hero Title:* 4rem - 5rem, tight letter spacing, uppercase/sentence case mix.
  - *Section Titles:* 2.5rem, semi-bold.
- **Body Text:** Medium-weight Sans-Serif. 1.125rem for readability, with a line height of 1.6.
- **Accents/Tags:** Monospaced or small-caps sans-serif for "Areas of Expertise" and categories (e.g., `SYSTEM-SCALING`, `AI-INTEGRATION`).

## 3. Color Palette
- **Backgrounds:**
  - Primary: `#FFFFFF` (White) or a very light `#F9F9F9` (Off-white).
  - Secondary: `#000000` (Black) for high-impact sections or footers.
- **Text:**
  - Primary: `#111111` (Deep Black).
  - Secondary/Muted: `#666666` (Gray) for descriptions and metadata.
- **Accent:** 
  - Subtle blues or purples for specific icons, though the site leans heavily toward a Monochrome + Tool-specific color (e.g., Figma purple, Framer blue) palette.

## 4. UI Components
- **Navigation Bar:** Minimalist top-docked bar. Links: `Cases`, `About`, `Resume`, `Contact`. Often stays visible as a "floating" pill or fixed header.
- **Project Cards:**
  - Large-scale imagery with subtle rounded corners.
  - Overlay or bottom-docked text containing title and a "Learn More" CTA.
- **Expertise Badges:** Small, pill-shaped or rectangular containers with all-caps text and a subtle background tint.
- **Testimonial Blocks:** Clean quotes with bold author names and smaller subtitle/role text.

## 5. Motion & Interaction
- **Entrance:** Elements slide up and fade in as the user scrolls.
- **Hover:** Project cards scale slightly (1.02x) or transition shadow depth.
- **Buttons:** Fill-in transitions or arrow animations (e.g., → moving right on hover).
